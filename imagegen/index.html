ComfyUI 연결 설정

PC에서 ComfyUI를 아래 옵션으로 실행해야 이 페이지에서 접속할 수 있습니다:
python main.py --enable-cors-header "*" --cuda-device 0
(--cuda-device 번호는 RX 9070이 잡힌 번호로.) 같은 PC의 브라우저에서 열면 127.0.0.1 그대로 쓰면 됩니다. 휴대폰 등 밖에서 쓰려면 Tailscale 같은 VPN으로 PC 주소를 넣고 --listen 옵션을 추가하세요. 현재 체크포인트 로더 기반 txt2img(SD1.5·SDXL·올인원 체크포인트)만 지원합니다.
